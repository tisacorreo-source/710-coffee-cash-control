# 710 Coffee Bar - Control de Caja

Prototipo web para apertura, cierre, movimientos de caja y correcciones/anulaciones.

## Comandos

```bash
npm install
npm run dev
npm run build
npm test
```

## Deploy

El proyecto está preparado como una app Next.js estándar para Vercel.

- Build command: `npm run build`
- Output: automático de Next.js
- Node.js: `>=22.13.0`

## Flujo del prototipo

- Abrir turno
- Cerrar turno
- Movimiento de caja
- Corrección / Anulación

Los formularios se limpian después de enviar. La conexión real a Google Sheets queda para el MVP.
